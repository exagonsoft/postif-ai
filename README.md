# PostifAI

## Overview
**PostifAI** is an AI-powered content generation platform that allows users to generate posts based on a given topic and up to five tags. It utilizes advanced AI models to create high-quality content and generate relevant images for the posts, making content creation faster and more efficient.

## Features
- Generate posts using AI by providing a topic and up to five tags.
- Create visually appealing images based on the generated content.
- Clean and modern UI built using Next.js.
- Seamless integration with OpenAI's GPT-4 and DALL-E models for text and image generation.

## Getting Started
Follow these instructions to set up and run PostifAI on your local machine.

### Prerequisites
- **Node.js** (v14 or higher)
- **NPM** or **Yarn**
- OpenAI API Key (for text and image generation)

### Installation
1. Clone the repository:

   ```bash
   git clone https://github.com/exagonsoft/postifai.git
   ```
2. Navigate to the project directory
   ```bash
   cd postifai
   ```
3. Install required dependencies
   ```bash
   npm install
   ```
   Or, if using Yarn:
   ```bash
   yarn install
   ```

### Configuration
1. Create a `.env.local` file in the root of the project and add the following     environment variable:

   ```bash
   OPENAI_API_KEY=your_openai_api_key
   ```
2. Replace your_openai_api_key with your actual OpenAI API key.

### Running the Application
- Start the Next.js development server:
   ```bash
   npm run dev
   ```
   Or, if using Yarn:
   ```bash
   yarn dev
   ```
- Navigate to http://localhost:3000 to view the application in your browser.

## How to Use
1. Enter a topic in the input field.
2. Provide up to five tags separated by commas.
3. Click Generate Post & Image to see the content and related image generated by AI.

## Technologies Used
- Next.js - React-based framework for building the frontend.
- OpenAI GPT-4 - For intelligent text generation.
- OpenAI DALL-E - For generating images based on the generated content.
- Axios - HTTP client for making API requests.
- Tailwind CSS - For component-based styling.
